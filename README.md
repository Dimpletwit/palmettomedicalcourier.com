# Palmetto Medical Courier Website

Static, mobile-friendly website for Palmetto Medical Courier.

## Included files

- `index.html` — the complete website, including all HTML and CSS
- `.nojekyll` — tells GitHub Pages to serve the files exactly as provided

## Upload to GitHub

1. Sign in to GitHub and create a new repository.
2. Give the repository a name such as `palmetto-medical-courier`.
3. Choose **Add file → Upload files**.
4. Upload `index.html`, `.nojekyll`, and this `README.md` file.
5. Select **Commit changes**.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Select **Save**.

GitHub will provide a website address after publishing finishes.

## Custom domain note

The domain `palmettomedicalcourier.com` is currently being connected to the existing Sites-hosted website. Do not change its DNS to GitHub Pages unless you intentionally decide to move hosting away from Sites.

## Editing

Open `index.html` in any code editor. The website uses one self-contained file with no external frameworks or required dependencies.
